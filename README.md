# ҰБТ Даярлық — Информатика

ҰБТ-ға информатикадан дайындалуға арналған статикалық сайт: 58 сабақ (2026–2027 оқу жылы),
бейнесабақтар, қосымша ресурстар, тапсырмалар және орындаған жұмысты ұстазға жіберу.

- Сервер, база, тіркелу жоқ. Тек HTML + CSS + JS, жинау (build) керек емес.
- GitHub Pages-те ешқандай баптаусыз жұмыс істейді (хэш-маршрут: `#/informatika/7`).
- Барлық сабақ **әрқашан ашық** — күнге байланысты жабылатын ештеңе жоқ.
- Оқушының ✅ белгілері мен аты тек өз телефонында (`localStorage`) сақталады.

## Файлдар

```
index.html            — бет қаңқасы және иконкалар
style.css             — дизайн (түстер, қаріп, компоненттер)
app.js                — сайт логикасы (өзгертудің қажеті жоқ)
data/config.js        — атау, ұстаз, Telegram сілтемесі, пәндер, жіберу санаттары
data/informatika.js   — силлабус: 58 сабақ, күндер, «Дайындық», бақылау сабақтары
data/resources.js     — бейне, қосымша материал, тапсырмалар (сабақ нөмірі бойынша)
assets/files/         — PDF, кесте т.б. файлдар
assets/videos/        — өз бейне файлдарың (mp4)
.nojekyll             — GitHub Pages файлдарды өзгертпеуі үшін
```

## 1. GitHub Pages-ке қою

1. GitHub-та жаңа **public** репозиторий жасаңыз (мысалы `ubt`).
2. Осы папкадағы барлық файлды жүктеңіз: **Add file → Upload files** (немесе `git push`).
   `.nojekyll` файлы да жүктелгенін тексеріңіз.
3. **Settings → Pages** бөліміне өтіңіз.
4. **Build and deployment → Source: Deploy from a branch**,
   **Branch: `main`**, папка **`/ (root)`** → **Save**.
5. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://<сіздің-логин>.github.io/<репозиторий>/`

> «Бөлісу» батырмасы (Web Share) тек HTTPS-те жұмыс істейді. GitHub Pages — HTTPS, бәрі дұрыс.

Файлды өзгерткен сайын GitHub сайтты өзі жаңартады (1–2 минут). Телефонда ескі нұсқа
көрінсе — бетті жаңартыңыз.

## 2. Бейнесабақ қосу

`data/resources.js` файлын ашып, сабақ нөмірін кілт ретінде жазыңыз:

```js
window.RESOURCES.informatika = {
  1: { video: "https://youtu.be/XXXXXXXXXXX" },
  2: { video: "https://drive.google.com/file/d/XXXXXXXX/view" },
  3: { video: "assets/videos/03.mp4" }
};
```

- **YouTube** — ең ыңғайлысы. Бейнені «Қол жетімділігі шектеулі» (Unlisted) етіп жүктесеңіз болады.
  `youtu.be/…`, `youtube.com/watch?v=…`, `/shorts/…` сілтемелерінің бәрі жарайды.
- **Google Drive** — файлға «Сілтемесі бар барлық адам көре алады» рұқсатын беріңіз.
- **Өз файлың** — `assets/videos/` ішіне салыңыз. GitHub бір файлға 100 МБ шектеу қояды,
  сондықтан ұзын бейнені YouTube-қа жүктеген дұрыс.

Бейне жоқ сабақта сайт «Бейнесабақ жақында қосылады» деген әдемі бос күйді көрсетеді.

## 3. Қосымша ресурстар мен тапсырмалар

```js
window.RESOURCES.informatika = {
  7: {
    video: "https://youtu.be/XXXXXXXXXXX",
    extra: [
      { title: "Сабақ конспектісі", url: "assets/files/07-konspekt.pdf", kind: "PDF" },
      { title: "Пайдалы сайт",      url: "https://example.com",           kind: "Сайт" }
    ],
    tasks: [
      { title: "1-тапсырма", text: "Тапсырманың қысқа сипаттамасы" },
      { title: "2-тапсырма", text: "Сілтемедегі тестті орында", url: "https://example.com" }
    ]
  },
  8: { extra: [ … ] }
};
```

- `kind` — карточкадағы қысқа белгі (PDF, Сайт, Файл, Кесте…). Бос қалса, өзі анықталады.
- Үтірлерді ұмытпаңыз: әр сабақтың `{ … }` блогынан кейін `,` қойылады.
- Файлды `assets/files/` ішіне жүктеп, сілтемені `assets/files/атауы.pdf` деп жазыңыз.

## 4. Жіберу санаттары

Әдепкі 4 санат `data/config.js` ішіндегі `categories` тізімінде:
Конспект, Практика, ҰБТ тапсырмалары, Үй тапсырмасы.

- Атауын (`title`) және түсіндірмесін (`hint`) өзгертуге болады.
- `id`-ді өзгертпеңіз — оқушылардың ✅ белгілері сол бойынша сақталады.
- Белгілі бір сабаққа ғана басқа санаттар керек болса — `resources.js`-те сол сабаққа
  `categories: [ … ]` қосыңыз.

Оқушы әр санатқа сурет таңдайды → «Бөлісу» басады → Telegram, WhatsApp т.б. өзі таңдайды.
Сурет 1600 px-ке дейін кішірейтіліп (JPEG) жіберіледі, қасында мәтін болады:
аты-жөні, пән, сабақ нөмірі мен тақырыбы, санат. Жіберу сәтті болса ✅ қойылады,
бас тартса — қойылмайды. Бөлісу мүмкіндігі жоқ браузерде сурет жүктеліп, мәтін көшіріледі
де, оқушы «Жібердім ✅» батырмасын басады.

## 5. Ұстазға жазу батырмасы

`data/config.js` ішінде:

```js
teacherLink: "https://t.me/сіздің_логин",
```

Бос қалса, батырма көрсетілмейді.

## 6. Физиканы (не басқа пәнді) қосу

1. `data/informatika.js` файлының көшірмесін `data/fizika.js` деп жасаңыз.
2. Ішінде `window.COURSES.informatika` → `window.COURSES.fizika`, `id: "fizika"`,
   `title: "Физика"` деп өзгертіп, физика силлабусын жазыңыз (сол форматта).
3. `data/config.js` ішінде физикаға `ready: true` қойыңыз.

Болды — `index.html` пен `app.js`-ке тиіспейсіз, сайт файлды өзі жүктейді.
Физика ресурстары `resources.js`-те `window.RESOURCES.fizika = { … }` ретінде жазылады.

Сабақ жолының форматы: `[нөмір, "кк.аа", "күн", "тақырып", "дайындық"]`.
Күн: `дс`, `сс`, `ср`, `бс`, `жм`, `сб`, `жс`. Жыл өзі есептеледі
(тамыз–желтоқсан → `startYear`, қаңтар–шілде → келесі жыл).
Тақырыпта «ЕНТ» не «ҰБТ» болса — «ҰБТ» тегі, «Практика» деп басталса — «Практика» тегі
автоматты қойылады. Бақылау сабақтары `controlLessons` тізімінде.

## 7. Тексеру

- «Келесі сабақ» бүгінгі күн бойынша анықталады. Басқа күнді тексеру үшін сілтемеге
  `?today=ЖЖЖЖ-АА-КК` қосыңыз: `…/?today=2026-11-20#/`
- Сайтты компьютерде ашу үшін папкада: `python3 -m http.server` → `http://localhost:8000`

## 8. Оқушы деректері

Аты-жөні мен ✅ белгілері тек оқушының өз браузерінде сақталады — ұстазға автоматты түрде
келмейді. Ұстаз жұмыстарды Telegram/WhatsApp арқылы алады. Оқушы браузер деректерін
тазаласа немесе басқа телефон алса, ✅ белгілері қайта басталады.
